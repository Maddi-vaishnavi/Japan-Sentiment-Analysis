# 🇯🇵 Japan Wikipedia Sentiment Analyzer

An AI-powered web application that analyzes the sentiment of text related to Japan using **Natural Language Processing (NLP)** and **Machine Learning** techniques. The app is built with **Streamlit** and provides real-time sentiment predictions along with visual insights.

---

## 🚀 Features

- 🔍 **User Input Sentiment Analysis**
  - Enter any sentence related to Japan
  - Predicts sentiment: **Positive, Negative, Neutral**

- 🧠 **Hybrid AI Approach**
  - Uses **TextBlob** for polarity detection
  - Uses a **trained ML model (sklearn)** for classification

- 📊 **Visualization Dashboard**
  - Probability distribution using bar charts
  - Tabular representation of predictions

- ☁️ **Word Cloud**
  - Displays most frequent words from Japan Wikipedia content

- 🌐 **Interactive UI**
  - Built using **Streamlit** for smooth user experience

---

## 🛠️ Tech Stack

- **Frontend/UI**: Streamlit  
- **Backend/ML**: Python, Scikit-learn  
- **NLP**: TF-IDF, TextBlob  
- **Visualization**: Matplotlib, Seaborn  
- **Others**: Pandas, WordCloud, Pickle
